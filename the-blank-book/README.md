# 《空白书》The Blank Book

> **类型：** 文学悬疑 / 心理小说
> **规模：** 30章 · 30万字 · 三篇式结构
> **致敬：** 但丁《神曲》三篇（遗忘篇/追寻篇/空白篇）

---

## 核心设定

**苏念**，32岁，古籍修复师。她发现自己的记忆正在被一页一页地擦除——每天醒来，她会失去一年。

第一天：2024年的记忆模糊了。
第二天：2023年消失了。
第三天：2022年也不见了。

她的记忆在倒退。当记忆退到18岁——她将遗忘一切。

在彻底变成一张白纸之前，她必须找到那个正在擦除她的人。

**而那个人，可能是她自己。**

---

## 主要人物

| 角色 | 身份 | 秘密 |
|---|---|---|
| **苏念** | 古籍修复师，32岁 | 她不只是遗忘——她在主动抹除 |
| **陈墨** | 神经科学家，苏念的前恋人 | 他发明了一种记忆干预技术 |
| **白露** | 苏念的妹妹，失踪五年 | 她的失踪是一切的起点 |
| **何远** | 古籍收藏家，苏念的雇主 | 他收藏的不只是古书 |
| **姜寒** | 心理医生 | 她知道苏念遗忘的真正原因 |
| **苏念的母亲** | 已故，作家 | 她留下的手稿藏着答案 |

---

## 三篇结构

### 第一篇：遗忘篇（第1-10章）· 10万字

苏念发现记忆正在消失。她试图对抗遗忘，记录下即将消失的一切。每失去一年，她就失去一部分自己。到第10章，她的记忆只剩下18岁。

### 第二篇：追寻篇（第11-20章）· 10万字

苏念带着18岁的记忆重新出发。她发现妹妹白露的失踪与自己的遗忘有关。她追踪陈墨的记忆技术，发现一个惊人的真相：遗忘不是被动发生的——是她自己选择了遗忘。

### 第三篇：空白篇（第21-30章）· 10万字

苏念发现母亲留下的未完成小说《空白书》预言了一切。她必须在记忆完全消失之前，完成母亲的小说，也完成自己的故事。最终章：苏念失去了所有记忆，但她在空白中找到了一种新的存在方式。
