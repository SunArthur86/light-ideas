## 核心设定

**苏念**，32岁，古籍修复师。她发现自己的记忆正在被一页一页地擦除——每天醒来，她会失去一年。在彻底变成一张白纸之前，她必须找到那个正在擦除她的人——而那个人，可能是她自己。

**方家七代女人**的清除——不是缺陷，是进化。每一代的蛋白积累，为的是第八代的诞生。空白之花开放的那一刻，八代人的记忆溶为一体。

## 核心主题

- **记忆与身份**：你不是你的记忆，你是写下记忆的那支笔
- **遗忘不是失去**：是蜕皮，旧记忆容不下新自我
- **空白不是终点**：是起点，盐溶在水里看不到盐，但水是咸的
- **手比脑子可靠**：身体记忆比意识记忆更持久
- **活**：不是一个动作，是一种状态
