# 《四梦归一》— 贯穿四大名著的虚幻小说

> 一个融合《红楼梦》《三国演义》《水浒传》《西游记》所有核心角色的跨界虚幻世界

## Goal

创作一部贯穿中国四大名著的虚幻小说，所有原著角色性格不变，事件人物跨界穿插为一部完整的虚幻故事。

## Core Idea

**太虚万界**——四块同源的世界基石（情石、义石、智石、灵石）各自演化出四个世界。当因果债务累积到临界点，四界屏障崩塌，贾宝玉与孙悟空（同为石生）、诸葛亮与公孙胜（同为道术奇才）、王熙凤与曹操（同为权谋高手）等人开始跨界相遇，最终共同面对万界存亡的抉择。

## Target Users

- 中国古典文学爱好者
- 对四大名著有基本了解的读者
- 喜欢跨界/奇幻题材的读者

## 叙事特色

- **叙述者**：空空道人（红楼梦），游历太虚万界的记录者
- **语言**：半文半白，融合骈文、史传体、话本体、章回体四种文体
- **结构**：30回，四卷渐进（界痕初现→太虚汇聚→命运交织→万界归一）

## Constraints

- 所有角色言行严格忠于原著性格，不可脱离原著依据
- 原著关键事件和结局不被修改
- 跨界现象有统一世界观逻辑支撑
- 覆盖57个核心角色，每个角色都要有戏份
