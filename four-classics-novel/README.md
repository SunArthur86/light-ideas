## 核心角色

- **贾宝玉**（情石持有者）→ 最终承载万界归一之珠
- **孙悟空**（灵石之魂）→ 石头兄弟、战力担当
- **宋江**（义石持有者）→ 从招安到共建、道不止一条
- **王熙凤**（棋手）→ 曹操选定、管四界如管内宅
- **诸葛亮**（智石前持有者）→ 遗命天罡八阵
- **关羽**（义之英灵）→ 武圣归义、万界守护
- **林黛玉**（情之化身）→ 焚稿合出师表、悲伤化为温柔力量
- **唐僧**（金蝉子）→ 渡四界众生、说服奎木狼
- **鲁智深 & 猪八戒**（喜剧兄弟）→ 结义、酒友
