## 二、家族关系图谱

### 四大家族

```
贾家（荣国府 + 宁国府）─── 王家 ─── 薛家 ─── 史家
    │                        │         │         │
    ├─ 贾母(史氏)───────────── 联姻 ──────── 史家
    ├─ 王夫人 ←──── 王家女儿
    ├─ 王熙凤 ←──── 王家侄女
    ├─ 薛姨妈 ←──── 王家女儿 → 薛宝钗
    └─ 贾元春 → 皇室(贵妃)
```

### 核心婚姻线
- **木石前盟**：宝玉 ↔ 黛玉（前世绛珠仙草还泪给神瑛侍者）
- **金玉良缘**：宝玉 ↔ 宝钗（通灵宝玉配金锁）
- 实际结局：宝玉娶宝钗（掉包计），黛玉含恨而亡

## 四、核心矛盾与主题

1. **木石前盟 vs 金玉良缘** — 自由爱情 vs 封建礼教
2. **仕途经济 vs 纯真情性** — 宝玉的反叛与坚守
3. **盛极必衰** — 贾府从烈火烹油到树倒猢狲散
4. **真假对立** — 甄（真）与贾（假）的哲学隐喻
5. **宿命与自由** — 太虚幻境的判词注定了所有人的命运
