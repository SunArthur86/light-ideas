# 🌌 文学星图 · Literary Constellation

> 100本世界名著 × 2700年文学宇宙的可交互可视化

## 设计理念

100本书 = 100颗星。每两本之间的"影响/回应/对话"关系 = 星座连线。
一张地图看懂2700年人类文学思想的传承与对话。

## 🎯 功能规划

### Phase 1 · 数据层（核心数据构建）
- BOOKS: 100本书元数据（id/title/author/country/year/genre/tags/importance 1-5）
- THEMES: 8大主题标签（战争/爱情/正义/自由/死亡/身份/信仰/自然）
- LINKS: 影响关系（~150条：teacher→student，回应/致敬/反叛/平行）
- ARCHETYPES: 10大角色原型（反叛者/流浪者/殉道者/智者/悲剧恋人/疯子/艺术家/战士/背叛者/救世主）
- ARCHETYPES_MAP: 每本书映射到1-3个原型
- TIMELINE: 12个文学时代

### Phase 2 · 星图可视化（Canvas/SVG）
- 100颗星：大小=重要性(1-5)，颜色=地区
- 星座连线：同流派/同主题/影响关系
- 力导向布局（简化版：手动预设+微调）
- 鼠标悬停显示信息卡
- 点击打开详情面板

### Phase 3 · 交互功能
- ⏳ 时间滑块：按时代过滤（古希腊→中世纪→文艺复兴→…→现代主义）
- 🎭 主题热力图：选择主题，高亮相关书籍和连线
- 🔗 影响链追踪：点一本书，高亮它的"老师"和"学生"
- 🧬 角色原型图谱：按原型分组，看同一原型在不同文化中的变体
- 🔍 搜索+过滤：按国家/流派/主题筛选

### Phase 4 · UI设计
- 深色太空主题（#0a0a1a背景）
- 侧边详情面板（同Atlas风格）
- 顶部工具栏（时代/主题/原型切换）
- 底部时间轴条
- 移动端适配
