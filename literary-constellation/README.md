## 🎯 功能

### ⭐ 星图视图
- 力导向布局：100+颗星按时代螺旋排列
- 大小=重要性(1-5)，颜色=国家/地区
- 影响链追踪：点击任意书，高亮"老师"和"学生"
- 主题/原型模式切换
- 时间滑块过滤
- 实时搜索

### 🗺️ 地图视图 (NEW!)
- Leaflet世界地图 + CartoDB暗色底图
- 150本书按城市标记
- 同城市书籍聚合显示
- 悬停显示城市全部书目
- 点击书目→地图飞到对应城市
- 时间/搜索联动过滤

### 🎛️ 通用功能
- 深色太空主题
- 侧边详情面板
- 8大主题 + 10大原型标签系统
- 影响关系连线 (紫=influence, 金=response, 绿=parallel)
- 键盘/鼠标交互
