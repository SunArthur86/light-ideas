# Four Classics Atlas — 四大名著地理可视化

> 基于 **Leaflet.js** 真实世界地图，覆盖中国到印度，39个名著地点 + 13条旅行路线

## 部署

推送 `index.html` 至 GitHub Pages 即可。纯静态单文件，依赖 CDN（Leaflet.js + CartoDB 暗色瓦片）。

## 功能

- **39 个地点**标注在真实经纬度地图上（含印度灵山·灵鹫山）
- **暗色地图瓦片**（CartoDB Dark Matter），四大名著分色标注
- **13 条路线**：文学4 + 自驾3 + 徒步3 + 骑行3，含距离/天数
- **19 条跨界连线**（四梦归一紫色虚线）
- **21 个人物关系**网络高亮
- **地点详情弹窗**：事件+人物+原文引用
- **时间线视图**：17个节点跨四部小说
- **实时搜索**地点
- **分享**带参数 URL
- **移动端**响应式 + 触摸缩放
- Leaflet 地图支持鼠标滚轮缩放、拖拽平移

## 覆盖范围

- 🇨🇳 中国全境（北京、南京、西安、赤壁、梁山、花果山等）
- 🇮🇳 印度（灵山·灵鹫山 24.95°N 85.05°E）
- 🇺🇿 中亚（库车、吐鲁番、哈密等丝路城市）
