# 🗺️ 四大名著地理可视化 Atlas

> 纯静态单文件 HTML，82 地点 + 18 路线 + 35 人物，四大名著地理全景

## 🎯 功能一览

### 数据层
- **82 地点** — 红楼梦18 + 三国22 + 水浒18 + 西游24，含古地名/海拔/关联事件
- **18 路线** — 自驾/徒步/骑行 × 四部小说，含难度评级(⭐-⭐⭐⭐⭐⭐)
- **35 人物** — 关联地点 + 出发旅行 + **人物关系网络图**(Force-directed)
- **30 跨界连线** — 四部小说间隐藏联系 + 四梦归一联动
- **31 时间线** — 从东汉末年到西游记的完整时间轴

### 视觉
- **4种底图** — 暗色 🌙 / 亮色 ☀️ / 地形 ⛰️ / 卫星 🛰️ 循环切换
- **SVG 自定义标记** — 红楼花/三国剑/水浒拳/西游云，按小说风格区分
- **统计仪表盘** — 按小说/省份/类型的可视化统计
- **移动端底部抽屉** — 55vh 可拉出面板，替代原隐藏方案

### 交互
- **故事时间轴播放** — 按时间自动 flyTo + 高亮对应小说标记，支持 1x/2x/4x 速度
- **热力图主题过滤** — ⚔️战争/📜诗词/💕爱情/🔮神话 四维筛选
- **人物关系图** — Canvas force-directed graph，可拖拽节点
- **旅行动画** — 选择路线/人物出发，地图跟随移动
- **搜索** — 实时过滤地点

### 四梦归一联动
- **📖 专属 tab** — 120回融合小说的30个关键章节映射到地图
- 按卷分组展示，点击章节 flyTo 对应地点
- 紫色 circleMarker 叠加层

### 高级功能
- **🖨️ 打印导出** — 生成按小说分组的高清地点清单
- **🔊 语音解说** — Web Speech API TTS，自动解说当前视野内地点
- **离线缓存** — Service Worker 缓存瓦片，断网可用

## 🚀 部署

直接部署 `index.html` 到任何静态托管：
```bash
# GitHub Pages
cp index.html docs/index.html
git push

# 本地预览
python -m http.server 8080
```

CDN 依赖：Leaflet.js + Noto Sans SC 字体
