# Four Classics Atlas — 四大名著地理可视化

> 四大名著 × 《四梦归一》跨界地理可视化交互地图

## 部署

将 `index.html` 推送至 GitHub 仓库，开启 GitHub Pages 即可访问。
纯静态单文件，无需构建。

## 功能

- **39 个地点**标注在交互式 SVG 地图上（含旅行路线补充城市）
- **12 个省份简化轮廓**作底图
- **按小说筛选**：红楼梦/三国/水浒/西游/四梦归一
- **13 条路线**分四类：
  - 📖 文学路线：取经路/北伐路/招安路/贾府兴衰
  - 🚗 自驾路线：三国遗迹/丝路取经/水浒好汉（含距离+天数）
  - 🥾 徒步路线：玄奘之路/赤壁古道/梁山泊（含距离+天数）
  - 🚴 骑行路线：三国征战/水浒江湖/红楼江南（含距离+天数）
- **19 条跨界连接**：紫色曲线贝塞尔动画
- **21 个核心人物关系网络**：点击人物高亮关联地点
- **暗色主题** 高对比度设计
- **3 个Tab页**：地点列表/路线动画/人物关系
