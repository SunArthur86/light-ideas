# Four Classics Atlas — 四大名著地理可视化

> 四大名著 × 《四梦归一》跨界地理可视化交互地图

## 部署

将 `index.html` 推送至 GitHub 仓库，开启 GitHub Pages 即可访问。
纯静态单文件，无需构建。

## 功能

- **33 个地点**标注在交互式 SVG 地图上，12 个简化省份轮廓作底图
- **按小说筛选**：红楼梦 / 三国 / 水浒 / 西游 / 四梦归一
- **路线动画**：取经路（金色）、北伐路（绿色）、招安路（蓝色）、贾府兴衰（红色）
- **跨界连接**：紫色虚线展示 19 条四梦归一跨界连接
- **人物关系**：21 个核心人物的关联地点和关系网络
- **暗色 / 亮色主题**切换
- **侧边栏**统计 + 地点列表 + 详情面板
- 点击地点/人物查看详情（事件、关联人物、四梦归一故事线）
