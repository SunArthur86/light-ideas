# Light Ideas

这是你的想法根目录。

后续你每提出一个新想法，我们就在这里创建一个独立文件夹，并逐步把想法补充成可以实现、可以迭代的内容。

## 目录规则

- 根目录：`/Users/sunqingguang/hermes/workspace/light-ideas`
- 一个想法对应一个文件夹
- 文件夹名统一使用英文小写，单词之间用 `-` 连接
- 每个想法文件夹至少包含一个 `README.md`
- 如果某个想法开始进入实现阶段，可以继续增加 `plan.md`、`tasks.md`、`notes.md`、`assets/` 等内容

## 协作约束

- 你负责提出想法、目标、偏好和调整意见
- 我负责帮你整理结构、补全文档、拆解需求，并继续推进实现
- 默认先从轻量文档开始，避免过度设计
- 只有当某个想法足够明确时，再进入代码、原型或正式实现

## 新想法创建方式

建议每次新建一个目录，例如：

- `light-ideas/ai-writing-coach`
- `light-ideas/focus-timer`
- `light-ideas/travel-planner`

然后把 [`TEMPLATE.md`](/Users/sunqingguang/hermes/workspace/light-ideas/TEMPLATE.md) 复制为该目录下的 `README.md`，再由我帮你补完整。
