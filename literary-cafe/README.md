## 📊 数据规模

- 30篇对话，约 42,000 字
- 涉及 150 本世界名著中的 60 个角色
- 跨越 2700 年、25 个国家
- 覆盖 10 大主题：犹豫/爱情/尊严/自由/权力/信仰/复仇/牺牲/孤独/创造

## 🎨 设计

- 咖啡馆暗色主题（`#0c0a08`）
- 暖金色调（`#c9a96e`）
- 单文件 HTML，零构建零部署
- 支持：点击阅读 / 键盘翻页（←→） / ESC 关闭

## 📂 文件

- `index.html` — 完整展示页（62KB，含全部30篇对话）
- `catalog.json` — 30对角色元数据
- `dialogues/` — 30篇 Markdown 原文
