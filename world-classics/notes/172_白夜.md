# 白夜

> *"A whole lifetime in a single night — that is happiness enough for me."*
> — 白夜

## 一句话
圣彼得堡四个白夜里的梦幻爱情，一个幻想家的独白

## 基本信息
| 项目 | 内容 |
|------|------|
| 原名 | White Nights |
| 作者 | 陀思妥耶夫斯基 |
| 国家 | 俄国 |
| 年代 | 1848年 |
| 类型 | 短篇小说集 |

## 核心主题
白夜是陀思妥耶夫斯基的代表作之一，属于俄国短篇小说文学的经典。作品通过深刻的叙事与细腻的描写，展现了俄国社会的精神面貌和人性的复杂面向。

## 关键人物
- **主角** — 承载着作者对人性与社会最深刻的思考
- **配角群** — 构建了丰富的社会画卷，每个角色都有独特的精神世界

## 文学风格
陀思妥耶夫斯基以其独特的叙事手法，将个人命运与社会背景紧密结合。语言精准而富有张力，情节跌宕起伏扣人心弦，人物塑造鲜明而富有象征意义。
