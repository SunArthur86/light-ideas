# 在流放地

> *"Guilt is never to be doubted."*
> — 在流放地

## 一句话
一座精密的死刑机器在荒岛上执行着令人毛骨悚然的惩罚

## 基本信息
| 项目 | 内容 |
|------|------|
| 原名 | In the Penal Colony |
| 作者 | 弗兰茨·卡夫卡 |
| 国家 | 奥地利 |
| 年代 | 1919年 |
| 类型 | 短篇小说集 |

## 核心主题
在流放地是弗兰茨·卡夫卡的代表作之一，属于奥地利短篇小说文学的经典。作品通过深刻的叙事与细腻的描写，展现了奥地利社会的精神面貌和人性的复杂面向。

## 关键人物
- **主角** — 承载着作者对人性与社会最深刻的思考
- **配角群** — 构建了丰富的社会画卷，每个角色都有独特的精神世界

## 文学风格
弗兰茨·卡夫卡以其独特的叙事手法，将个人命运与社会背景紧密结合。语言精准而富有张力，情节跌宕起伏扣人心弦，人物塑造鲜明而富有象征意义。
