# 一生

> *"Life is never as good or as bad as one thinks."*
> — 一生

## 一句话
贵族女子让娜从少女到老妇的一生，理想在现实中不断破灭

## 基本信息
| 项目 | 内容 |
|------|------|
| 原名 | Une Vie |
| 作者 | 居伊·德·莫泊桑 |
| 国家 | 法国 |
| 年代 | 1883年 |
| 类型 | 小说 |

## 核心主题
一生是居伊·德·莫泊桑的代表作之一，属于法国小说文学的经典。作品通过深刻的叙事与细腻的描写，展现了法国社会的精神面貌和人性的复杂面向。

## 关键人物
- **主角** — 承载着作者对人性与社会最深刻的思考
- **配角群** — 构建了丰富的社会画卷，每个角色都有独特的精神世界

## 文学风格
居伊·德·莫泊桑以其独特的叙事手法，将个人命运与社会背景紧密结合。语言精准而富有张力，情节跌宕起伏扣人心弦，人物塑造深邃而立体。
