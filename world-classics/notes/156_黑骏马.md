# 黑骏马

> *"My doctrine is this, that if we see cruelty or wrong that we have the power to stop, we should try to stop it."*
> — 黑骏马

## 一句话
一匹马的自传，以动物的视角揭露维多利亚时代对动物的残酷

## 基本信息
| 项目 | 内容 |
|------|------|
| 原名 | Black Beauty |
| 作者 | 安娜·塞维尔 |
| 国家 | 英国 |
| 年代 | 1877年 |
| 类型 | 小说 |

## 核心主题
黑骏马是安娜·塞维尔的代表作之一，属于英国小说文学的经典。作品通过深刻的叙事与细腻的描写，展现了英国社会的精神面貌和人性的复杂面向。

## 关键人物
- **主角** — 承载着作者对人性与社会最深刻的思考
- **配角群** — 构建了丰富的社会画卷，每个角色都有独特的精神世界

## 文学风格
安娜·塞维尔以其独特的叙事手法，将个人命运与社会背景紧密结合。语言精准而富有张力，情节跌宕起伏扣人心弦，人物塑造深邃而立体。
