# 赛季模式

> 排位赛 + 锦标赛 + 赏金赛三种竞技模式，赛季制运营

---

## 赛季周期

- 每赛季 **4 周**
- 赛季末结算段位，发放奖励
- 每赛季新增1个"赛季限定"机制（如限定法宝/限定地形图/限定计策）

---

## 一、排位赛

### 段位系统

| 段位 | 图标 | 所需积分 | 奖励 |
|------|------|----------|------|
| **青铜** | 🥉 | 0-999 | 基础卡背 |
| **白银** | 🥈 | 1000-1499 | 银色卡框 |
| **黄金** | 🥇 | 1500-1999 | 金色卡框 + 1张随机精英角色卡 |
| **铂金** | 💎 | 2000-2499 | 铂金特效 + 1张随机传说角色卡 |
| **钻石** | 👑 | 2500-2999 | 钻石特效 + 限定法宝 |
| **王者** | 🐉 | 3000+ | 王者专属称号 + 全角色解锁 |

### 积分规则

| 结果 | 积分变化 |
|------|---------|
| 胜利（正常） | +25 |
| 胜利（碾压——3分钟内） | +35 |
| 胜利（逆转——己方仅剩1人） | +40 |
| 失败（正常） | -15 |
| 失败（惜败——对方仅剩1人） | -10 |
| 平局 | +5 |
| 逃跑/断线 | -30 |

### 匹配规则

- 优先匹配同段位 ±1 段
- 匹配超时 30 秒后扩大范围至 ±2 段
- 连胜 3 局后匹配到更高段位对手（"连胜挑战"）

### Ban/Pick 流程

1. **Ban 阶段**（双方各禁3个角色）
2. **Pick 阶段**（交替选角色，先Ban后Pick）
3. **装备阶段**（选择法宝）
4. **布阵阶段**（选择兵法阵 + 军规）
5. **部署阶段**（将角色放到4×4格子）
6. **开战**

## 二、锦标赛

### 赛制

- 每周末举办，**64人淘汰赛**
- 报名费：100 金币
- 单败淘汰，BO1（决赛 BO3）

### 奖池

| 名次 | 奖励 |
|------|------|
| 🥇 冠军 | 5000 金币 + 限定传说法宝 + "赛事冠军"称号 |
| 🥈 亚军 | 3000 金币 + 限定精英法宝 |
| 🥉 季军 | 1500 金币 + 随机传说角色卡 |
| 前8 | 500 金币 |
| 前16 | 200 金币 |
| 参与 | 50 金币 |

### 特殊规则

- **盲选模式**：Pick 阶段不公开选择，同时对亮
- **随机地图**：每局随机选择一个特殊地图
- **时间限制**：每回合 30 秒，超时自动跳过

---

## 三、赏金赛

### 机制

- 自由匹配，**无段位限制**
- 可自定义规则（金币入场费）
- 赢家通吃（扣 10% 手续费）

### 特殊模式

| 模式 | 规则 | 乐趣点 |
|------|------|--------|
| **乱斗模式** | 96角色随机选4，不可换 | 看脸 |
| **镜像对决** | 双方用同一套阵容 | 纯操作 |
| **极限模式** | 灵力减半，冷却翻倍 | 每步都关键 |
| **全明星** | 只能用传说角色 | 史诗碰撞 |
| **草根赛** | 只能用普通角色 | 小人物逆袭 |
| **双打** | 2v2，每人控制2个角色 | 团队配合 |

## 四、赛季限定

### 第一赛季：赤壁之焰

- **限定地形图**：赤壁之战（中央大河+火场）
- **限定法宝**：东风箭（诸葛亮专属限定法宝——借东风自动触发）
- **限定规则**：火系技能伤害+50%

### 第二赛季：梁山聚义

- **限定地形图**：梁山泊（中央大水域）
- **限定法宝**：聚义金牌（宋江限定——招安成功率+50%）
- **限定规则**：水系角色 SPD+2

### 第三赛季：大闹天宫

- **限定地形图**：天庭（全山地+火场）
- **限定法宝**：定海神针（悟空限定——金箍棒伤害+100%）
- **限定规则**：飞行单位无视地形

### 第四赛季：金陵旧梦

- **限定地形图**：大观园（全森林+城池）
- **限定法宝**：判词卷（黛玉限定——焚稿必杀无冷却）
- **限定规则**：BEN 类技能效果+100%

## 五、经济系统

### 货币

| 货币 | 获取方式 | 用途 |
|------|---------|------|
| **金币** | 比赛/任务/每日登录 | 购买法宝/角色卡/入场费 |
| **钻石** | 赛季结算/成就/付费 | 购买限定皮肤/特效 |
| **荣誉点** | 排位赛专用 | 兑换排位专属奖励 |

| 任务 | 奖励 |
|------|------|
| 完成3场排位赛 | 100 金币 |
| 使用4部小说各1个角色 | 80 金币 |
| 使用一个三十六计卡 | 50 金币 |
| 赢得1场赏金赛 | 150 金币 |
| 部署一个传说角色 | 60 金币 |

| 百战百胜 | 连胜10场 | 500 金币 + 称号 |
| 计谋大师 | 单场打出5张计策卡 | 300 金币 |
| 绝境翻盘 | 己方仅剩1人获胜 | 钻石×10 |
