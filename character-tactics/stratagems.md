# 三十六计卡牌完整列表

## 一级计（冷却 1 回合）

| 计策 | 类型 | 效果 |
|------|------|------|
| 瞒天过海 | 隐匿 | 隐藏一个友方角色 1 回合（不可被选为目标） |
| 声东击西 | 控制 | 强制敌方一个角色朝指定方向攻击（可能打空或打友方） |
| 暗渡陈仓 | 移动 | 将一个友方角色秘密移至敌方阵线后方空格 |
| 无中生有 | 抽牌 | 从牌库额外抽取 1 张计策卡 |
| 抛砖引玉 | 牺牲 | 以 1 个普通技能的冷却为代价，使必杀技冷却清零 |
| 打草惊蛇 | 侦察 | 揭露敌方所有隐藏状态（陷阱/隐身/手牌） |
| 指桑骂槐 | 减益 | 指定一个敌方角色，其 LOY-3 持续 2 回合 |
| 以逸待劳 | 防御 | 指定友方角色本回合不行动，下回合全属性+2 |

## 二级计（冷却 2 回合）

| 计策 | 类型 | 效果 |
|------|------|------|
| 借刀杀人 | 反弹 | 使敌方一个角色对另一敌方造成其 MAR×1 伤害 |
| 围魏救赵 | 攻疗 | 对敌方后排造成 INT×1 伤害，同时治疗己方前排 HP 最低者 BEN×2 |
| 调虎离山 | 位移 | 将敌方一个角色强制移至指定相邻空格 |
| 欲擒故纵 | 蓄力 | 本回合放弃攻击，下回合全队 MAR+3 |
| 偷梁换柱 | 替换 | 替换场上一个友方角色为手牌中的另一角色（HP 继承） |
| 关门捉贼 | 封锁 | 封锁敌方一个角色 1 回合（不可移动、不可攻击） |
| 混水摸鱼 | 混乱 | 场上每有一个负面状态，随机对敌方造成 3 点伤害 |
| 苦肉计 | 牺牲 | 自伤 20% HP，使一个友方必杀技立即就绪 |
| 趁火打劫 | 追击 | 对 HP 低于 50% 的敌方角色造成额外 MAR×2 伤害 |
| 隔岸观火 | 观望 | 本回合跳过行动，获得 2 点灵力储备 |
| 釜底抽薪 | 摧毁 | 移除敌方一个角色的一个增益效果 |
| 假途伐虢 | 借道 | 使一个友方角色本回合可穿越敌方角色所在格 |

## 三级计（冷却 3 回合）

| 计策 | 类型 | 效果 |
|------|------|------|
| 走为上 | 撤退 | 将一个友方角色撤回手牌，同时回复其 100% HP |
| 连环计 | 连锁 | 将两个敌方角色"锁链"——一个受伤害时另一个也受 50% |
| 美人计 | 蛊惑 | 目标敌方角色下回合攻击最近的友方（忠诚背叛） |
| 反客为主 | 反转 | 占领敌方一个阵位格，该格变为己方控制区域 |
| 空城计 | 虚张 | 己方角色不足时触发：所有敌方 INT-3 持续 2 回合 |
| 远交近攻 | 外交 | 与对手交换各 1 张手牌（可看牌后选择给哪张） |
| 上屋抽梯 | 围困 | 将一个敌方角色困在原地 2 回合，同时其周围 2 格内友方受伤+50% |
| 树上开花 | 增益 | 指定一个友方，其所有属性等于场上最高对应属性值，持续 1 回合 |
| 借尸还魂 | 复活 | 以 50% HP 复活一个已阵亡的友方角色（每局限 1 次） |
| 借题发挥 | 升级 | 指定一个普通技能，本回合效果翻倍 |
| 擒贼擒王 | 精准 | 指定一个敌方角色，本回合所有攻击只对该角色有效且伤害+50% |
| 将计就计 | 反制 | 抵消对手打出的 1 张计策卡，并将其效果反弹给对手 |
| 以退为进 | 诱敌 | 己方一个角色后退 1 格，下回合 SPD+5 且攻击范围+2 |
| 攻心为上 | 瓦解 | 目标敌方角色下回合不可使用技能（只能普通攻击） |
| 抛砖引玉·极 | 终极 | 牺牲 1 个友方角色，使另一友方必杀技无冷却连发 2 次 |
