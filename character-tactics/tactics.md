## 二、克制关系

```
爆发流 → 克制 → 计策流（一轮秒杀法师，计策来不及放）
计策流 → 克制 → 防御流（控制链让防御无用武之地）
防御流 → 克制 → 爆发流（扛住第一轮爆发，反击磨死）
速攻流 → 克制 → 法术流（切后排法师，AOE打不到）
法术流 → 克制 → 控制流（AOE无视单体控制）
控制流 → 克制 → 速攻流（控制住刺客，脆皮被反杀）

简图：
爆发 → 计策 → 防御 → 爆发（三角克制）
速攻 → 法术 → 控制 → 速攻（三角克制）
```

## 三、属性克制

| 攻方优势属性 | 克制 | 守方弱势属性 | 原因 |
|-------------|------|-------------|------|
| 高MAR(武) | → | 低LOY(义) | 物理伤害直接击穿低防御 |
| 高INT(智) | → | 低SPI(灵) | 计策对灵力低者效果加倍 |
| 高SPI(灵) | → | 低INT(智) | 灵力攻击无法被智谋化解 |
| 高SPD(速) | → | 低SPD(速) | 先手优势，多打一轮 |
| 高BEN(仁) | → | 持久战 | 治疗量碾压伤害量 |

## 四、起手策略

### 先手阵容（SPD总和 > 22）

推荐：速攻流（赵云+时迁+晴雯+哪吒，SPD合计=6+8+7+8=29）

**第一回合关键操作**：
1. 时迁发动"鼓上蚤"偷取敌方一张手牌
2. 赵云发动"七进七出"穿越到敌方后排
3. 晴雯+哪吒双打后排法师
4. 打出"暗渡陈仓"将时迁移到敌方后排

### 后手反制阵容（SPD低但防御高）

推荐：防御流（刘备+林冲+贾母+沙僧，SPD合计=4+6+2+3=15）

**第一回合关键操作**：
1. 贾母"老祖宗庇佑"保护核心
2. 刘备"仁德天下"全队回复
3. 打出"以逸待劳"蓄力
4. 林冲前排待命准备反击

## 五、常见战术 Combo

### Combo 1：焚稿+趁火打劫（极限爆发）

**触发条件**：黛玉HP < 30%
**操作**：
1. 黛玉发动"焚稿绝唱"（自残50%HP → SPI×3 全体灵力伤害）
2. 打出"趁火打劫"计策卡（对HP<50%敌人追加MAR×2伤害）
3. 队友武松发动"景阳伏虎"（对HP<30%目标伤害翻倍）

**伤害计算**：SPI×3 + MAR×2 + MAR×4 = 9+20+40 = **69点理论伤害**（足以秒杀大部分角色）

**弱点**：黛玉自残后极其脆弱，如果第一波没杀完就会被反杀

---

### Combo 2：四界棋局+借刀杀人（控制链）

**触发条件**：凤姐INT≥9，曹操在场上
**操作**：
1. 凤姐发动"权谋之眼"查看对手手牌
2. 根据手牌信息，曹操发动"借刀杀人"让敌方互殴
3. 凤姐发动"四界棋局"控制敌方核心攻击友方
4. 打出"将计就计"准备反弹对手的反制

**控制时长**：连续2回合敌方核心无法自主行动

**弱点**："打草惊蛇"可揭露手牌，"将计就计"可反弹

---

### Combo 3：天罡五雷+混水摸鱼（AOE连招）

**触发条件**：敌方有3+负面状态
**操作**：
1. 公孙胜发动"天罡五雷"（全体SPI×3雷伤）
2. 诸葛亮发动"八阵图"（困住敌方+降速）
3. 打出"混水摸鱼"（每个负面状态+3伤害）
4. 太上老君"炼丹炉"持续灼烧

**伤害计算**：SPI×3×4 + 3×负面数 + 持续灼烧 = **36+9+持续**

**弱点**：单体伤害分散，可能打不死高HP角色

---

### Combo 4：石头兄弟+大闹天宫（共鸣爆发）

**触发条件**：宝玉和悟空同时在场
**操作**：
1. 跨界共鸣自动触发：宝玉+悟空双方SPD+2
2. 悟空SPD提升至9，先手发动"大闹天宫"（全体MAR×2物理伤害）
3. 宝玉发动"万界归一"（全体回复+灵力伤害）
4. 打出"树上开花"（宝玉属性等于场上最高值）

**特殊**：石头兄弟共鸣是被动触发，无需消耗灵力

**弱点**：如果宝玉或悟空任一被击倒，共鸣消失

---

### Combo 5：招安+美人计（忠诚崩塌）

**触发条件**：敌方有高LOY角色（如关羽LOY=10）
**操作**：
1. 宋江发动"招安"（目标LOY归零1回合）
2. 打出"美人计"（目标攻击最近友方）
3. 关羽LOY=10→0，被美人计控制攻击友方
4. 关羽攻击伤害MAR×1=10，打在自己人身上

**特殊**：对LOY越高的角色效果越震撼——因为他们的MAR通常也很高

**弱点**：宋江需要近身，且"招安"冷却3回合

---

### Combo 6：空城计+以退为进（虚张声势）

**触发条件**：己方场上角色不足3人
**操作**：
1. 打出"空城计"（敌方全体INT-3，持续2回合）
2. 诸葛亮发动"空城退敌"（诱敌+反射50%伤害）
3. 打出"以退为进"（后退1格→SPD+5，攻击范围+2）
4. 下回合全面反攻

**适用场景**：己方残血时的翻盘战术

**弱点**：如果对手识破不打，空城计的INT降低仍有效但浪费回合

## 七、三层策略组合阵容（兵法阵+军规+计策）

### 组合一：闪电战（全速压制）

| 层级 | 选择 | 理由 |
|------|------|------|
| **兵法阵** | 作战阵 | 全体SPD+1，首回合额外灵力 |
| **军规** | 兵贵神速 | 移动+1，移动3格后伤害+20% |
| **核心计策** | 暗渡陈仓+声东击西 | 速度加成下移动计策翻倍 |
| **阵容** | 赵云+时迁+晴雯+哪吒 | SPD合计29，全游戏最快 |

**战术**：第一回合赵云七进七出→时迁暗渡陈仓→晴雯+哪吒双突后排。作战阵给全员SPD+1，加上兵贵神速的移动+1，第一回合就能穿越全场。

| 层级 | 选择 | 理由 |

**战术**：军形阵+铁血意志=双倍防御加成。刘备+贾母双治疗，林冲前排反击，沙僧护后排。即使被打到残血，铁血意志+军形不屈=两条命。
