# 《字阵》— 四大名著策略卡牌游戏策划方案

> 一款以中国四大名著角色为基础的策略卡牌对战游戏

---

## 一、游戏概述

**名称**：字阵（Glyph Tactics）
**类型**：策略卡牌对战（TCG-like）
**人数**：1v1（可扩展 2v2）
**平台**：HTML5 网页 / 实体卡牌
**核心机制**：三十六计 + 角色技能 + 阵位博弈

### 核心概念

每位玩家从四大名著中各选1名角色组成**4人阵容**。角色分布在4×4的阵位上，通过移动、攻击、释放技能、发动**三十六计**来击败对手阵容。

---

## 二、六维属性体系

每个角色拥有六项基础属性，初始值 1-10：

| 属性 | 缩写 | 含义 | 典型高值角色 |
|------|------|------|-------------|
| **武** (Martial) | MAR | 物理攻击力、近战伤害 | 关羽、武松、鲁智深 |
| **智** (Intellect) | INT | 策略伤害、计策成功率 | 诸葛亮、曹操、凤姐 |
| **仁** (Benevolence) | BEN | 治疗量、辅助效果 | 唐僧、刘备、贾母 |
| **义** (Loyalty) | LOY | 防御力、减伤、反击 | 宋江、关羽、林冲 |
| **灵** (Spirit) | SPI | 法术伤害、灵力上限 | 悟空、公孙胜、黛玉 |
| **速** (Speed) | SPD | 行动顺序、移动范围 | 悟空、赵云、时迁 |

### 属性总点数

- 普通角色：25-30 点
- 精英角色：31-35 点
- 传说角色：36-40 点

## 四、技能体系

每个角色拥有 **1个必杀技 + 1-3个普通技能**。必杀技消耗灵力（SPI×2点），普通技能冷却 1-3 回合。

### 传说角色技能详表

#### 贾宝玉
- **【必杀】万界归一**：将场上所有角色的因果线连接，友方全体回复 BEN×2 HP，敌方全体受到 SPI×1 灵力伤害。若宝玉 HP 低于 30%，效果翻倍。
- **【技能】碎玉引路**：标记一个敌方角色为"因果焦点"，所有友方攻击该目标时 +2 MAR。
- **【技能】石头兄弟**：与孙悟空同时在场时，双方 SPD+2。

#### 林黛玉
- **【必杀】焚稿绝唱**：牺牲自身 50% HP，对全体敌方造成 SPI×3 灵力伤害。HP 越低伤害越高（焚稿=极限反击）。
- **【技能】葬花**：在指定格放置"花坟"标记，站在花坟上的友方每回合回复 BEN×1 HP。
- **【技能】还泪**：每回合自动回复 HP 最低的友方角色 BEN×1 HP。

#### 王熙凤
- **【必杀】四界棋局**：操控敌方一个角色在下回合攻击其友方（将计就计）。成功率 = INT×10%。
- **【技能】铁腕管家**：所有友方角色 LOY+2，持续 2 回合。
- **【技能】空城退敌**：以自身为诱饵，吸引敌方一个角色攻击自己，同时将伤害的 50% 反射给攻击者。
- **【技能】权谋之眼**：查看对手手牌中一张三十六计卡。

#### 关羽
- **【必杀】青龙偃月**：对前方直线 3 格内所有敌方造成 MAR×3 物理伤害。若击杀任一目标，义之英灵觉醒：MAR+3 持续 2 回合。
- **【技能】义薄云天**：指定一个友方，关羽代替其承受所有伤害，持续 1 回合。
- **【技能】武圣之威**：被动——关羽在场时，所有友方武将 MAR+1。

#### 诸葛亮
- **【必杀】天罡八阵**：在场上布下阵法，阵内友方全属性+3，阵内敌方全属性-2。阵法持续 3 回合。
- **【技能】借东风**：改变场上风向，所有火属性技能伤害翻倍，持续 2 回合。
- **【技能】空城计**：诸葛亮不移动不攻击 1 回合，若敌方未攻击他，回复 SPI×3 灵力。

#### 曹操
- **【必杀】宁教我负天下**：对所有敌方造成 INT×2 策略伤害，同时所有友方获得 INT×1 护盾。
- **【技能】望梅止渴**：回复全体友方 30% HP（谎言也是力量）。
- **【技能】割发代首**：牺牲自身 10% HP，获得一次完全闪避。
- **【技能】挟天子**：控制一个 INT 低于曹操的敌方角色 1 回合。

#### 孙悟空
- **【必杀】齐天大圣**：变化为齐天大圣形态，全属性+5，持续 3 回合。形态结束后 HP 降为 1。
- **【技能】七十二变**：变身为场上任意一个角色，复制其一个技能，使用 1 次后恢复。
- **【技能】火眼金睛**：揭露场上所有隐身/陷阱/伪装。
- **【技能】筋斗云**：瞬间移动到场上任意空格（无视距离）。

#### 唐僧
- **【必杀】金蝉渡化**：选择一个敌方角色，进行"渡化判定"——若唐僧 BEN > 对方 LOY，对方加入友方 2 回合。
- **【技能】紧箍咒**：对悟空或任一妖族角色造成 SPI×2 伤害并使其眩晕 1 回合。
- **【技能】心经**：每回合自动为相邻友方回复 BEN×1 HP。
- **【技能】慈悲为怀**：被动——唐僧受到致命伤害时，有 BEN×10% 概率免死一次。

#### 宋江
- **【必杀】替天行道**：召唤 2 名梁山好汉（随机从牌库中抽取水浒角色卡）临时加入战场 2 回合。
- **【技能】招安**：将一个敌方普通/精英角色"招安"——使其 LOY 归零 1 回合（忠诚动摇）。
- **【技能】兄弟同心**：被动——每有一个水浒友方在场，宋江全属性+1。

#### 公孙胜
- **【必杀】天罡五雷**：对场上所有敌方造成 SPI×3 雷属性灵力伤害。
- **【技能】灵魂出窍**：公孙胜灵魂脱离肉身 1 回合——灵魂无敌但无法攻击，可用于侦察敌方手牌。
- **【技能】破宿符**：对一个星宿/神仙系角色造成 SPI×4 伤害（对凡人无效）。

## 五、三十六计卡牌系统

除角色卡外，双方各持 **5 张三十六计卡** 作为"手牌"。每回合可打出 0-1 张。

### 计策分级

| 等级 | 计策 | 效果 |
|------|------|------|
| **一级计**（冷却1回合） | 瞒天过海 | 隐藏一个友方角色 1 回合（不可被选中） |
| | 声东击西 | 强制敌方一个角色攻击指定方向 |
| | 暗渡陈仓 | 将一个友方角色秘密移至敌方阵线后方 |
| | 无中生有 | 从牌库额外抽取 1 张计策卡 |
| | 抛砖引玉 | 以 1 个普通技能为代价，使必杀技冷却清零 |
| **二级计**（冷却2回合） | 借刀杀人 | 使敌方一个角色对另一敌方造成其 MAR 的伤害 |
| | 围魏救赵 | 对敌方后排造成 INT 伤害，同时治疗己方前排 |
| | 调虎离山 | 将敌方一个角色强制移至相邻格 |
| | 欲擒故纵 | 本回合不攻击，下回合全队 MAR+3 |
| | 偷梁换柱 | 替换场上一个友方角色为手牌中的另一角色 |
| | 关门捉贼 | 封锁敌方一个角色 1 回合（不可移动） |
| | 混水摸鱼 | 场上每有一个负面状态，随机对敌方造成 3 点伤害 |
| | 苦肉计 | 牺牲...详见 stratagems.md |
