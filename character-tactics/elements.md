# 五行生克系统

> 金·木·水·火·土五行元素克制，角色按属性分配元素，影响伤害和技能效果

---

## 五行克制

```
金 → 克 → 木 （金伐木）
木 → 克 → 土 （木扎根破土）
土 → 克 → 水 （土挡水）
水 → 克 → 火 （水灭火）
火 → 克 → 金 （火熔金）
```

**克制效果**：攻击克制目标时伤害+25%，被克制时伤害-25%

---

## 角色五行分配

### 分配原则

- **金**：刚猛武将、锐利角色（MAR 为主）
- **木**：生长治愈、灵活角色（BEN 为主）
- **水**：智慧谋略、流动角色（INT/SPD 为主）
- **火**：爆发激情、毁灭角色（高伤害技能）
- **土**：防御坚守、稳重角色（DEF/LOY 为主）

## 五行与地形联动

| 地形 | 五行 | 效果 |
|------|------|------|
| 山地 | 土 | 土系角色 DEF+30%，水系角色 SPD-1 |
| 水域 | 水 | 水系角色回复+50%，火系角色伤害-30% |
| 森林 | 木 | 木系角色 BEN+3，金系角色射程-1 |
| 城池 | 金 | 金系角色 MAR+2，木系角色受治疗效果-20% |
| 火场 | 火 | 火系角色伤害+30%，水系角色每回合损失 5% HP |

## 五行共鸣

当己方 4 个角色中有特定五行组合时触发共鸣：

| 组合 | 名称 | 效果 |
|------|------|------|
| 金+木+水+火 | 四行归一 | 全体全属性+1，免疫五行克制劣势 |
| 双金+双火 | 金火炼狱 | 金系和火系角色伤害各+20% |
| 双木+双水 | 生生不息 | 每回合全体回复 5% HP |
| 双土+双金 | 铜墙铁壁 | 全体 DEF+20%，土系角色免疫击退 |
| 三同+一异 | 五行偏盛 | 主五行角色属性+3，但被克五行伤害+50% |
| 金+水+木+土 | 仁者无敌 | BEN 类技能效果+30%，LOY+2 |
